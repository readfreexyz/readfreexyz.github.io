Read Free

Read the news outlets boycotted over their coverage of Israel's genocide in Gaza, without paying them a cent. Read Free is an extension for Chrome and Firefox on your computer that gets you past their paywalls. The first time you read each one, it tells you why it's boycotted and links to the source.

Version 0.25.0, released 2026-11-24 · Open source on GitHub

On a phone? Read Free works in Chrome or Firefox on a computer. Send yourself this page's link and open it there.

1Get it

In Chrome, on a Mac or Linux Updates itself

Paste this into Terminal. It installs the newest release and checks for a new one every hour, and it only installs releases signed with Read Free's key.

curl -fsSLO https://readfree.xyz/install.sh && sh install.sh

At the end it shows the folder to load in step 2. On a Mac, macOS may then say a background item was added: that's the hourly check, which System Settings lists under Login Items as Read Free updater.

In Chrome, on Windows Updates itself

Paste this into PowerShell (type PowerShell in the Start menu). It installs the newest release and checks for a new one every hour, and it only installs releases signed with Read Free's key.

irm https://readfree.xyz/install.ps1 -OutFile install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

At the end a window opens with the folder to drag in step 2. Task Scheduler lists the hourly check as Read Free updater.

In Firefox Updates itself

Add to Firefox Read Free 0.25.0

Firefox asks whether this site may install an add-on, then shows what Read Free does. It needs Firefox 140 or later. That's all: step 2 is only for Chrome.

It's signed by Mozilla, and Firefox lists browsing activity because an article's address goes to archive.today when its text has to come from there. When an update adds a site, Read Free's button shows a !, and its settings have a button to allow it.

In Chrome, on any computer Updated manually

Download Read Free 0.25.0 zip, 183 KB

Unzip it, name the folder Read Free, and keep it where it can stay, such as Documents: Chrome loads it from there.

To update, when Read Free says a new version is out (an arrow on its toolbar button): download it here, unzip it, name it Read Free too, and put it in place of the old folder. Then click the reload arrow on Read Free in chrome://extensions. It's the same folder, so your settings and tally stay.

2Load it in Chrome, once

Edge, Brave, Vivaldi and Dia work the same way (in Dia, the page is dia://extensions).

  1. Paste chrome://extensions into the address bar and turn on Developer mode, top right. Leave it on: with it off, Chrome turns Read Free off.
  2. Drag the folder onto that page: the one the install script opened in Finder or File Explorer (it's called extension), or your Read Free folder. Or click Load unpacked and choose it. The script copies its path for you: on a Mac, press Cmd+Shift+G in that window and paste it; on Windows, paste it into the Folder box and click Select Folder.
  3. Read Free's watermelon shows in the toolbar, next to the address bar. If it doesn't, click the puzzle piece there and pin Read Free.
  4. Reload any tabs that were already open.

This page sets no cookies. On readfree.xyz its host, Cloudflare, adds a script that counts visits by country, browser, device and the page that linked here, and measures how fast the page loads. Cloudflare says it stores nothing in your browser and doesn't keep your IP address; most ad blockers stop it. The page loads nothing else from outside, and the extension has no analytics.
