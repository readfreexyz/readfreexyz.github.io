Read Free

Read the news outlets boycotted over their coverage of Israel's genocide in Gaza, without paying them a cent. Read Free is an extension for Chrome and Firefox on your computer that gets you past their paywalls. The first time you read each one, it tells you why it's boycotted and links to the source.

Version 0.26.3, released 2026-11-26 · Open source on GitHub

Read Free is a financial boycott of news outlets over their pro-Israel coverage of the genocide of Palestinians.

  • A browser extension that opens their paywalled articles.
  • Open source, with no ads, analytics or trackers.

What Firefox tells you

Read Free is signed by Mozilla. Firefox lists browsing activity because an article's address goes to archive.today when its text has to come from there. It needs Firefox 140 or later.

When an update adds a site, Read Free's button shows a !, and its settings have a button to allow it.

The first way: Paste one line

  1. On a Mac or Linux: Copy this line. curl -fsSLO https://readfree.xyz/install.sh && sh install.sh
  2. On Windows: Copy this line. irm https://readfree.xyz/install.ps1 -OutFile install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
  3. On a Mac: Open Terminal: press ⌘ Command and Space together, type Terminal, and press Return.
  4. On Windows: Open PowerShell: press the Windows key, type PowerShell, and press Enter.
  5. On Linux: Open a terminal.
  6. On a Mac: In Terminal, press ⌘ Command and V together to paste the line, then press Return. Your Mac may warn you first, as it does with anything pasted from a website. To go on, confirm that you want to paste. If you'd rather not, choose Download a file above: it works just as well.
  7. On Windows: In PowerShell, press Ctrl and V together to paste the line, then press Enter. If you'd rather not, choose Download a file above: it works just as well.
  8. On Linux: Paste the line there and press Enter.
  9. On a Mac: Wait a few seconds while some text appears. Then a Finder window opens, showing a folder called extension: that's Read Free. Don't open the folder, just leave the window there. This page may open again too, in a new tab, at the next part. macOS may say that a background item was added: that's how Read Free updates itself.
  10. On Windows: Wait a few seconds while some text appears. Then a File Explorer window opens, showing a folder called extension: that's Read Free. Don't open the folder, just leave the window there. This page may open again too, in a new tab, at the next part.
  11. On Linux: Wait until it shows the folder it put Read Free in.
What does this line do?

It downloads Read Free's installer and runs it. The installer gets the newest release and puts it in a folder, then checks for a new one every hour. It only installs releases signed with Read Free's key.

System Settings lists the hourly check under Login Items, as Read Free updater.

-ExecutionPolicy Bypass lets Windows run the installer, for this run: it changes no settings. Task Scheduler lists the hourly check as Read Free updater.

You can read it first, on GitHub: install.sh or install.ps1.

Or the second way: Download a file

  1. Download Read Free 0.26.3 zip, 214 KB
  2. On a Mac: Open your Downloads folder and double-click Read Free.zip. A folder called Read Free appears next to it.
  3. On Windows: Open your Downloads folder. Right-click Read Free (its icon has a zipper), choose Extract All, then Extract. You get another Read Free, a folder without a zipper. Double-clicking the one with the zipper only shows what's in it.
  4. On Linux: Unzip it, into a folder called Read Free.
  5. On a Chromebook: In the Files app, open Downloads, right-click Read Free.zip, and choose Extract all (or Extract). You get a folder called Read Free.
  6. Move the Read Free folder into Documents, and leave it there. Chrome uses it from there: Read Free stops working if the folder is moved or deleted later.
  7. On a Chromebook: Move the Read Free folder into My files, and leave it there. Chrome uses it from there: Read Free stops working if the folder is moved or deleted later.

Then, add it to Chrome

  1. Copy chrome://extensions
  2. Open a new tab, paste it into the address bar at the top, and press Return or Enter. That's the Extensions page. Keep this tab too: come back to it for the next steps.
  3. On the Extensions page, turn on Developer mode, at the top right, and leave it on. It's Chrome's own switch, for adding an extension from a folder. With it off, Chrome turns Read Free off.
  4. If you pasted the line: Go to the Extensions page. Then bring back the window with the extension folder: click Finder in the Dock or File Explorer in the taskbar. Drag the folder onto the Extensions page, anywhere on it.
    Can't find the folder, or can't drag it?

    Copy this: ~/Library/Application Support/Read Free/extension or %LOCALAPPDATA%\Read Free

    Then, on the Extensions page, click Load unpacked. In the window that opens, press ⌘ Command, Shift and G together, paste, press Return, and choose the folder.

    Then, on the Extensions page, click Load unpacked. In the window that opens, click the bar at the top that shows where you are, paste, and press Enter. Click the extension folder once, then Select Folder.

  5. If you pasted the line, on Linux: Copy this, the folder Read Free is in: ~/.local/share/read-free/extension. On the Extensions page, click Load unpacked, press Ctrl and L together in the window that opens (in most of them), paste, and choose the folder.
  6. Or, if you downloaded the file: On the Extensions page, click Load unpacked, at the top left. Choose the Read Free folder in Documents or My files: click it once, then click Select Folder.
    It says the manifest is missing?

    Then it's the wrong folder. Choose the Read Free folder that has a file called manifest in it. It may be inside the one you chose.

Using Edge, Brave, Vivaldi or Dia?

The same steps work. The switch and the buttons may be somewhere else on the page, and in Dia the page is dia://extensions.

✓That's it

A tab opens by itself, saying Read Free is on. Reload any news tabs that were already open.

Read Free's button is the watermelon next to the address bar. If you don't see it, click the puzzle piece there and pin Read Free.

Later: updates

If you pasted the line, there's nothing to do: Read Free updates itself.

If you downloaded the file, Read Free's button shows an arrow when a new version is out.

How to update it then
  1. Download Read Free 0.26.3 and unzip it.
  2. Delete the old Read Free folder from where you keep it. Move the new one there, and give it the same name.
  3. Go to chrome://extensions and click the reload arrow on Read Free. Your settings and tally stay.

In Firefox: There's nothing to do: Firefox updates Read Free by itself.
